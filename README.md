# SogaKey 輸入法

SogaKey 是我自己做的免費 Android 輸入法，以 [Fcitx5 for Android](https://github.com/fcitx5-android/fcitx5-android) 為基礎。目標很單純：**Gboard 般順手的注音打字、一個鍵盤搞定多國語言，再加上 AI 語音輸入與翻譯**。

## 下載

到 [Releases 頁面](https://github.com/word-light/fcitx5-android1/releases/tag/latest) 下載，每次更新都會自動編譯並覆蓋同一個版本。

| 檔案 | 用途 | 必裝？ |
|---|---|---|
| `1-SogaKey-main.apk` | 主程式（內含日文轉換引擎與詞庫，檔案較大） | 必裝 |
| `2-SogaKey-zhuyin-plugin.apk` | 注音（新酷音） | 要打注音就裝 |
| `3-SogaKey-korean-plugin.apk` | 韓文（Hangul） | 要打韓文就裝 |
| `4-SogaKey-japanese-plugin.apk` | 日文輸入法項目（Anthy） | 要打日文就裝 |

先裝 1，再裝需要的外掛。只更新主程式時，不必重裝外掛；外掛有改動才需要重裝。

## 我加了哪些功能

### 注音
- **打到一半，詞就先跳出來**：只打前幾個音，候選列就會先猜出整個詞，展開候選可看到整頁。
- **一聲就是按空白鍵**：打完音後按空白鍵是一聲；字已經完整、沒有未打完的音時，再按空白鍵會選第一個候選字。
- **鍵上滑動直接打數字與標點**：注音鍵右下角的小字就是滑動後會打出的數字或符號。按住鍵時，上方（或下方）會出現**懸浮小框**預覽，滑過去放開就輸入。
- 表情符號建議偏向常用表情，打字時順手可選。

### 日文
- **12 鍵滑動（フリック）鍵盤**：按住假名鍵，四周會展開十字選字框，往要的方向滑動後放開。゛゜小 鍵可循環切換濁音、半濁音、小字（は → ば → ぱ）。
- **羅馬字鍵盤**：按 `ABC` 切換，打 `kyou` 會轉成「きょう」，支援促音（kka → っか）、撥音（nn）與拗音（sha、cha、kya）。
- **漢字轉換**：使用 [Sumire](https://github.com/KazumaProject/JapaneseKeyboard) 的轉換核心與 Mozc 系詞庫。空白鍵切換候選，Enter 送出，點候選字上字；只選部分字時，剩下的假名會留著繼續轉換。
- **會學習**：選過的詞下次會排得比較前面。
- 可展開候選列，一次看更多選項。

### 一個鍵盤，多國語言
- 注音、倉頡、日文、韓文、英文、手寫都在同一個鍵盤。倉頡只顯示手機字型能顯示的字，避免出現空白方框。
- **長按空白鍵＝秒切英文**，再長按一次切回原本的輸入法，不用一直轉地球鍵。
- 點地球鍵依序切換各語言；長按地球鍵可直接選輸入法。

### AI 語音輸入與翻譯
- 麥克風鍵一按就說，辨識後由 Gemini 整理成通順文字。
- 說完可一鍵翻成**英文、日文、韓文或中文**，確認後直接送出，不用切 App、不用複製貼上。
- 需自備金鑰：Gemini（必填）、Groq（選填，語音辨識更快）。金鑰只存在你的手機裡。

### 其他
- **手寫輸入**：麥克風旁的筆形按鈕，手寫板精簡，不佔太多畫面。
- **主題**：設定 → 主題，可選現成配色，或點「新主題」自訂顏色與背景圖片。

## 找不到功能？看這裡

| 想做的事 | 怎麼做 |
|---|---|
| 切到英文 | **長按空白鍵**（要按住約一秒，感覺到震動才會切）。英文要排在輸入法清單的**第一個**才會正確來回切換 |
| 長按空白鍵沒反應 | 到 設定 → 虛擬鍵盤 → 「空格鍵長按行為」，選「切換啟用／停用」。以前改過設定的話，舊設定會蓋掉新預設值 |
| 打數字、標點 | 注音鍵上有小字的，**按住往上（或下）滑**。方向可到 設定 → 虛擬鍵盤 → 「划動輸入標點及數字」改成上划或下划 |
| 注音一聲 | 打完音按**空白鍵** |
| 打日文 | 先在輸入法清單新增「日本語 (Anthy)」，並裝好 4 號外掛。切到日文後，左下的 `ABC` 切羅馬字，`あ` 切回滑動鍵盤 |
| 日文轉漢字 | 輸入假名後，**空白鍵**換候選、**Enter** 送出，或直接點候選列；候選列右側的展開鈕可看更多 |
| 用 AI 語音 | 先到 AI 語音設定頁填金鑰，再按鍵盤上的麥克風 |
| 換顏色或背景 | 設定 → 主題 |

## 小提醒

- 日文第一次使用時需要載入詞庫，會多等幾秒，之後就很快。
- 因為內建日文詞庫，主程式 APK 比一般輸入法大。
- 還在持續改進中，遇到問題或有想法，歡迎到 [Issues](https://github.com/word-light/fcitx5-android1/issues) 回報。
